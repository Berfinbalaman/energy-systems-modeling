# cogeneration system simulation(MATLAB)
Initial MATLAB script('ornek10revize.m')developed for my undergraduate mechanical engineering graduation thesis on a cogeneration cycle.
## Scope & Notes
- **Focus:** Thermodynamic state-point calculations,power/heat balance,and operating cost/benefit analysis for a cogeneration system.
- **Dependencies:** Calls 'refpropm' for fluid properties; requires a local REFPROP setup to run directly.
- **Status:** Work in progress (baseline thesis model).
